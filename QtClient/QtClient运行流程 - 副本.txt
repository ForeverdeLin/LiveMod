# QtClient 运行流程文档

## 概述

QtClient 是一个基于 Qt 框架的流媒体客户端应用程序，用于接收解码服务器TCP端口传来的h264数据、
和使用OpenGL渲染播放来自流媒体服务器的音视频流，同时使用websocket提供控制界面用于管理推流参数。

## 程序启动流程

### 1. 程序入口 (main.cpp)

```
main(int argc, char *argv[])
├── 创建 QApplication 对象
│   └── 管理应用程序生命周期和事件循环
├── 创建 MainWindow 对象
│   └── 主窗口初始化（见下方详细流程）
├── 显示窗口 (w.show())
└── 进入事件循环 (a.exec())
    └── 处理用户交互、定时器、网络事件等
```

**关键代码：**
```cpp
QApplication a(argc, argv);
MainWindow w;
w.show();
return a.exec();
```

## MainWindow 初始化流程

### 2. MainWindow 构造函数执行顺序

```
MainWindow::MainWindow()
├── 1. 设置UI界面
│   ├── ui->setupUi(this)  // 加载Qt Designer生成的UI文件
│   └── setWindowTitle("智能直播推流控制台")
│
├── 2. 创建OpenGL视频显示组件
│   └── m_pOpenGLWidget = new CCOpenGLWidget(this)
│       └── 用于渲染YUV视频帧
│
├── 3. 初始化UI组件 (initUI)
│   ├── 获取UI文件中的控件指针（滑块、按钮、列表等）
│   ├── 将OpenGL组件添加到视频显示区域布局
│   └── 连接所有信号槽（滑块值变化、按钮点击等）
│
├── 4. 初始化设备列表 (initDevices)
│   ├── 枚举系统摄像头设备 → 填充到下拉框
│   └── 枚举系统麦克风设备 → 填充到下拉框
│
├── 5. 初始化WebSocket连接 (initWebSocket)
│   ├── 创建 WebSocketControlClient 实例
│   ├── 连接信号槽（connected/disconnected/messageReceived）
│   └── 连接到服务器 (ws://192.168.236.101:8080)
│
├── 6. 初始化音频输出 (initAudioOutput)
│   ├── 设置音频格式：44.1kHz, 16bit, 双声道
│   ├── 创建 QAudioOutput 对象
│   └── 启动音频输出，获取 I/O 设备指针
│
└── 7. 创建TCP视频客户端并连接
    ├── 配置网络连接信息（IP: 192.168.236.101, Port: 30000）
    ├── 创建 CCVideoClient 实例
    ├── 启动TCP连接 (StartSocketConnection)
    └── 设置回调函数
        ├── 视频回调：MainWindow::updateVideoData
        └── 音频回调：MainWindow::updateAudioData
```

## TCP视频客户端运行流程

### 3. CCVideoClient 启动流程

```
CCVideoClient::StartSocketConnection()
├── 1. 创建TCP Socket
│   ├── socket(AF_INET, SOCK_STREAM, 0)
│   └── 设置为非阻塞模式
│
├── 2. 启动连接线程 (runWaitConnectionThread)
│   └── 使用 select() 检测连接状态
│       └── 连接成功后设置 m_bConnected = true
│
├── 3. 启动接收线程 (runRecvAVStreamThread)
│   └── 持续接收音视频流数据（见下方详细流程）
│
├── 4. 启动心跳线程 (sendKeepAlivePacketThread)
│   └── 每秒发送一次心跳包，保持连接
│
└── 5. 启动音视频同步线程 (runAVSyncThread)
    └── 同步音视频播放时间戳（见下方详细流程）
```

### 4. 接收音视频流线程流程

```
runRecvAVStreamThread()
├── 创建H.264解码器 (H264Decoder)
├── 创建AAC解码器 (AACDecoder)
│   └── 初始化：44.1kHz, 2声道
│
└── 循环接收数据
    ├── 等待连接建立 (m_bConnected == true)
    │
    ├── 接收消息头 (CC_MsgHeader)
    │   ├── 验证消息ID ("CCTC")
    │   └── 检查消息类型 (MSGHEADER_TYPE_AVSTREAM)
    │
    ├── 接收音视频数据
    │   └── 根据 subType 判断类型
    │
    ├── 处理视频数据 (CONTENT_AVSTREAM_VIDEO)
    │   ├── 接收H.264编码数据
    │   ├── 解码为YUV420P格式
    │   └── ProcessVideoFrame()
    │       ├── 深拷贝YUV数据
    │       └── 放入视频队列 (m_videoQueue)
    │
    └── 处理音频数据 (CONTENT_AVSTREAM_AUDIO)
        ├── 接收AAC编码数据
        ├── 解码为PCM格式
        └── ProcessAudioFrame()
            ├── 深拷贝PCM数据
            └── 放入音频队列 (m_audioQueue)
```

### 5. 音视频同步线程流程

```
runAVSyncThread()
└── 循环同步处理
    ├── 等待连接建立
    │
    └── SyncAVFrames() - 同步音视频帧
        ├── 初始化同步时钟
        │   ├── 等待第一帧音视频数据
        │   ├── 记录起始时间 (m_startTime)
        │   └── 记录初始时钟 (m_audioClock, m_videoClock)
        │
        ├── 处理音频帧（音频作为主时钟）
        │   ├── 从音频队列取出帧
        │   ├── 计算应该播放的时间
        │   ├── 如果到播放时间 → 调用音频回调函数
        │   └── 更新音频时钟
        │
        └── 处理视频帧（以音频时钟为基准）
            ├── 从视频队列取出帧
            ├── 计算与音频时钟的时间差
            ├── 如果时间差在阈值内 (±50ms) → 调用视频回调函数
            ├── 如果视频太旧 → 丢弃（丢帧）
            └── 如果视频太新 → 等待
```

## 视频渲染流程

### 6. 视频数据回调流程

```
CCVideoClient 接收线程
    ↓ (解码H.264为YUV)
放入视频队列
    ↓
音视频同步线程
    ↓ (时间戳同步)
调用回调函数
    ↓
MainWindow::updateVideoData() [静态回调]
    ↓ (获取MainWindow实例)
MainWindow::updateYUVFrame()
    ↓
CCOpenGLWidget::RendVideo()
    ├── 检查分辨率变化，重新分配缓冲区
    ├── 复制YUV数据到缓冲区
    │   ├── Y平面数据
    │   ├── U平面数据
    │   └── V平面数据
    ├── 标记数据已更新 (m_bUpdateData = true)
    └── 触发重绘 (update())
        ↓
    CCOpenGLWidget::paintGL() [Qt自动调用]
        ├── 绑定YUV纹理
        ├── 使用Shader程序
        ├── 绘制矩形（覆盖整个窗口）
        └── YUV → RGB 转换（在Shader中完成）
```

### 7. OpenGL渲染详细流程

```
CCOpenGLWidget::initializeGL() [初始化时调用]
├── 初始化OpenGL函数指针
├── 启用深度测试
├── 设置背景颜色（黑色）
├── 生成3个纹理对象（Y、U、V）
└── 初始化Shader程序
    ├── 加载顶点着色器 (vertex.vert)
    ├── 加载片段着色器 (fragment.frag)
    └── 链接Shader程序

CCOpenGLWidget::paintGL() [每次重绘时调用]
├── 清除颜色缓冲和深度缓冲
├── 绑定Shader程序
├── 更新YUV纹理数据
│   ├── 绑定Y纹理 → 上传Y平面数据
│   ├── 绑定U纹理 → 上传U平面数据
│   └── 绑定V纹理 → 上传V平面数据
├── 设置顶点属性（顶点坐标、纹理坐标）
├── 绘制矩形（2个三角形组成）
└── YUV到RGB转换（在片段着色器中完成）
```

## 音频播放流程

### 8. 音频数据回调流程

```
CCVideoClient 接收线程
    ↓ (解码AAC为PCM)
放入音频队列
    ↓
音视频同步线程
    ↓ (时间戳同步)
调用音频回调函数
    ↓
MainWindow::updateAudioData() [静态回调]
    ↓ (获取MainWindow实例)
MainWindow::playPCMData()
    ├── 检查音频I/O设备有效性
    └── 写入PCM数据到音频输出设备
        └── m_pAudioIODevice->write(pcmData, pcmSize)
            ↓
        QAudioOutput 自动播放
            ↓
        系统音频设备输出
```

## 用户交互流程

### 9. 美颜参数控制流程

```
用户拖动滑块
    ↓
信号槽触发
    ↓
onSmoothSliderChanged() / onBrightSliderChanged() / ...
    ├── 将滑块值 (0-100) 转换为浮点数 (0.0-1.0)
    ├── 保存到成员变量
    └── updateFilterParamsToServer()
        ├── 检查WebSocket连接状态
        └── 发送JSON命令到服务器
            └── WebSocketControlClient::updateFilterParams()
                ├── 构造JSON对象
                │   └── {"action": "update_filter", "params": {...}}
                └── 通过WebSocket发送
```

### 10. 推流控制流程

```
用户点击"开始推流"按钮
    ↓
onStartStreamClicked()
    ├── 检查WebSocket连接状态
    ├── 发送 startStreaming() 命令
    ├── 更新推流状态标志 (m_bStreaming = true)
    ├── 禁用开始按钮，启用停止按钮
    └── 更新状态标签显示"推流中..."

用户点击"停止推流"按钮
    ↓
onStopStreamClicked()
    ├── 检查WebSocket连接状态
    ├── 发送 stopStreaming() 命令
    ├── 更新推流状态标志 (m_bStreaming = false)
    ├── 启用开始按钮，禁用停止按钮
    └── 更新状态标签显示"推流已停止"
```

### 11. RTMP地址管理流程

```
用户添加RTMP地址
    ↓
onAddRTMPUrlClicked()
    ├── 从输入框获取URL文本
    ├── 添加到列表控件
    ├── 发送 addRTMPUrl() 命令到服务器
    └── 清空输入框

用户移除RTMP地址
    ↓
onRemoveRTMPUrlClicked()
    ├── 获取列表选中项
    ├── 从列表移除
    └── 发送 removeRTMPUrl() 命令到服务器
```

    ↓

    ├── connected → onWebSocketConnected()

## 关键技术点总结

### 多线程架构
1. **连接线程**：负责TCP连接建立和状态检测
2. **接收线程**：负责接收和解码音视频数据
3. **心跳线程**：定期发送心跳包保持连接
4. **同步线程**：根据时间戳同步音视频播放
5. **主线程**：Qt事件循环，处理UI交互和渲染

### 音视频同步机制
- **音频作为主时钟**：以音频播放时间为基准
- **时间戳同步**：根据帧的时间戳计算播放时间
- **丢帧策略**：视频帧太旧时丢弃，避免延迟累积
- **阈值控制**：允许±50ms的时间差误差

### 数据流转
```
服务器 → TCP Socket → 接收线程 → 解码器 → 队列 → 同步线程 → 回调函数 → UI渲染/音频播放
```

### 控制命令流转
```
用户操作 → 信号槽 → 槽函数 → WebSocket客户端 → JSON命令 → 服务器
```

## 配置文件说明

- **服务器IP地址**：硬编码在代码中 `192.168.236.101`
- **TCP端口**：30000（视频流）
- **WebSocket端口**：8080（控制命令）
- **音频格式**：44.1kHz, 16bit, 双声道

## 注意事项

1. **线程安全**：音视频队列使用互斥锁保护
2. **内存管理**：YUV和PCM数据需要深拷贝，避免数据被覆盖
3. **资源释放**：程序退出时需要正确释放所有资源
4. **错误处理**：网络连接失败、解码失败等情况需要适当处理
5. **性能优化**：队列大小限制防止内存溢出，丢帧策略防止延迟累积
